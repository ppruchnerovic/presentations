# A Computer Is All You Need

**Steren Giannini (Director and Founder — Google Cloud Run)**

`Track: AI Agents` · `Type: Keynote/Talk` · `Stage: Mainstage`

[Watch the recording](https://www.youtube.com/watch?v=SciZ3SBKcto) · [Session page](https://app.wearedevelopers.com/events/16/session/767)

## Abstract

Developers and AI Agents all have in common the need for on-demand computers in the cloud. In this session, we'll show how Google Cloud Run delivers on-demand computers with zero overhead and pay-per-use pricing for all of your apps and agents.

We will deep dive with live demos into three new workloads that can benefit from Cloud Run's on demand computers:
1. Deploy your apps vibe coded in Google AI Studio to the cloud without needing a credit card,
2. Run your personalized long running background agents, like OpenClaw or Hermes, on Cloud Run Instances,
3. Give your scalable agents the ability to execute untrusted code fast and securely with the new Cloud Run sandboxes.

## Speakers

### Steren Giannini

*Director and Founder — Google Cloud Run*

Steren is a founding member of Google Cloud Run, and is today the product leader for Google Cloud's serverless portfolio (Cloud Run, Cloud Run functions, App Engine, Tasks, Scheduler, Eventarc, Workflows). Steren also notably founded Google Cloud Carbon Footprint.

Steren is an engineer turned product manager, he graduated from École Centrale (France). Before joining Google, he was CTO of a startup building connected objects and multi device solutions.
