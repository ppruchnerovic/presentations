# Is it still C#? Practical systems programming with .NET (war stories included)

**Szymon Kulec (Lead Developer Advocate — RavenDB)**

`Track: Languages & Runtimes` · `Type: Keynote/Talk` · `Stage: Stage 6 - powered by Microsoft`

`#C#` `#Databases` `#.NET` `#Performance`

## Abstract

We built a database in .NET and pushed the runtime to its absolute limits. In this talk, we'll dissect the engineering decisions we made, extracting hard-won lessons you can use to build truly high-performance software. Expect battle-tested techniques you can apply to any demanding .NET service. Even if it's not a database.

Join us to learn how to survive the sharp edges of systems programming. We'll explore:
1. JSON and Beyond
2. The Memory Game
3. Taming the State Machine
4. Beyond the Cache Line
5. Vectorize Everything!
6. Surviving the Ecosystem
