# Completing the Feedback Loop

**Nimrod Kor (Co-founder and CTO — Baz)**

## Abstract

Coding via AI agents is a solved problem. We've come a long way from the "tab experience" Cursor has given us to approaches like "Ralph Wiggum". And almost every time - the AI comes up short, leaving you to implement the finishing touches (if not more). In this talk we will explore how we can give the agent  the leg-up it needs to really complete the task.

## Speakers

### Nimrod Kor

*Co-founder and CTO — Baz*

Nimrod Kor is a software engineer specializing in code analysis, cloud security, and developer tooling. As the #1 contributor to Checkov, he has helped shape best practices in Infrastructure as Code (IaC) security. His work on open-source projects like Checkov, Yor, and Airiam—focused on creating and analyzing code—has been central to his past talks.
