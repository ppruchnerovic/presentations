# Meta Harnesses: What the JS Framework Wars Teach Us About What Is Next for AI Agents

**Victor Savkin (CTO and Co-founder — Nx)**

`Track: Strategy & Innovation` · `Type: Keynote/Talk` · `Stage: Mainstage`

[Watch the recording](https://www.youtube.com/watch?v=MLPSIWvEBt0) · [Session page](https://app.wearedevelopers.com/events/16/session/1052)

## Abstract

In 2016, in the middle of the JS framework wars, Next.js changed the game. The first meta framework, it fixed the pain points of using React in real orgs. In 2026, the same shift is coming to agents. A new layer is forming on top of agent harnesses to fix the structural limits of using agents in real orgs.

*CTO and Co-founder — Nx*
