# Designing for Agents Will Make You Better at Designing for Humans

**Dana Lawson (CTO — Netlify)**

`Track: AI Agents` · `Type: Keynote/Talk` · `Stage: Stage 11`

`#Agents`

[Watch the recording](https://www.youtube.com/watch?v=eiP7ZLRYgc4) · [Session page](https://app.wearedevelopers.com/events/16/session/1023)

## Abstract

Dana Lawson, CTO of Netlify, makes the case that designing for agents, a discipline known as agent experience (AX), is quietly rewriting the software development lifecycle. Coding agents are in your workflow now. Most platforms still treat them like humans who type faster. But if you get it right, designing for agents doesn't come at the expense of human experience. The same work that lets an agent deploy without touching the plumbing lets an engineer debug a failed build faster.
