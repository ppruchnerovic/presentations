## Abstract

As agents move into production developer workflows, quality is no longer just about better model output. It is about context selection, tool orchestration, task boundaries, token usage, latency, and cost.

This session looks at how to build higher-quality agents without simply throwing bigger prompts at the problem. We'll cover practical patterns for improving agent behavior: scoping tasks, managing context, reducing unnecessary model calls, designing better tool use, and measuring quality against cost.

You'll leave with a technical framework for building agents that are more reliable, more efficient, and less expensive to run. Smarter agents. Smaller prompts. Fewer burned credits.
