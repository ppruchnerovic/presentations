**Justin Reock (Deputy CTO — DX)**

## Abstract

The session debunks the myth of the 10x engineer and argues that 10x organizations are real — backed by data showing an 11x productivity difference between organizations (vs. only 21% difference between engineers within the same org).

Key themes include:

- Why developer productivity is a systems problem, not a people problem

- The evolution from DORA metrics to modern DevEx frameworks (SPACE, DX Core 4: Speed, Effectiveness, Quality, Impact)

- How to create a continuous improvement flywheel: Assess → Prioritize → Act

- Measuring GenAI's impact on developer productivity

- Real-world examples (Pfizer reduced incident resolution time by 33%, increased deployment frequency by 22%)
