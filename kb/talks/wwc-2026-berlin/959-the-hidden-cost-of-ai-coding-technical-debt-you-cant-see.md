# The Hidden Cost of AI Coding: Technical Debt You Can’t See

**Maish Saidel-Keesing (Developer Advocate — AWS)**

`#AI Coding Assistants` `#Legacy` `#Productivity`

## Abstract

AI coding tools boost your productivity today, but at what price? This session uncovers the invisible technical debt accumulating in codebases built with AI assistants. Explore how generated code creates maintenance nightmares, why test coverage doesn’t tell the whole story, and what happens when your team can’t explain how their own code works. Learn to spot warning signs early, implement measures that preserve code quality, and build systems you can actually debug.

*Developer Advocate — AWS*

Maish Saidel-Keesing is a Senior Developer Advocate at AWS.

He's been working in tech for over 20 years, and if there's one thing that's been consistent throughout his career, it's this: if something can be automated, it should be. He's an automation junkie. Always has been.
