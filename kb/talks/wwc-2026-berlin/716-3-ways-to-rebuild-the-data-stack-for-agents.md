## Abstract

AI agents are becoming core users of the data tools we've used for decades. Seemingly everyone has a dozen agents querying their data warehouse, building dashboards, or writing their data pipelines.

This session will share what we've learned at MotherDuck while building data products for users that rely on AI agents. We'll cover:

- Tradeoffs of owning the agent harness vs. the BYO agent model
- The role of CLIs and Model Context Protocol in the data stack
- How to create products agents can discover, sign up for, and use
